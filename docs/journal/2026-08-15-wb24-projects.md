# WB-24 — named project list, board picker, project badges

## What was asked

User: "erlaube mir weitere projekte anzulegen" — filed as WB-24 and worked
visibly in the chat session (handover lineage active).

## What I did

- `src/werkbank/projects.py`: `add_project(config_path, name, path)` — German
  validation errors (empty name, relative/missing path, duplicate name
  case-insensitive), persists into config.json under in-process lock + flock
  sidecar `.config.lock` (board threads and chat sessions can both write).
  5 new tests (red first), total suite 84 green.
- server: `POST /api/projects` (400 with the German reason on ValueError, which
  the existing handler already maps), `projects` in config defaults; config.json
  seeded with `{"Werkbank": <repo>}`.
- board.html: header button "📁 Projekte" with list+add dialog (stays open for
  adding several); create/detail dialogs use a project `<select>` fed from
  config.projects — a ticket whose path is not in the list gets its raw path
  injected as an extra option (legacy tickets stay valid and visible); cards
  show a 📁 name badge (reverse lookup, fallback: last path segment; full path
  as tooltip). Both script blocks node --check OK.
- create-ticket skill v2: resolve project NAMES via config.projects, ask on
  unknown names, add_project for new ones.
- Endpoint verified live after restart: error paths (missing dir, duplicate
  name) → 400 German; success path covered by unit tests (no scratch project
  left in the real config).

## What I tried that didn't work — and why

Nothing failed.

## Decisions made

- Dropdown-only project field (no free-text input anymore): the projects dialog
  is the one place paths are typed and validated; unknown legacy paths surface
  as an injected option instead of a text field.
- No delete/rename endpoint yet — config.json is hand-editable and the need is
  unproven; revisit when the user asks.

## Follow-ups

- When the user registers a real second project, the pull-ticket skill install
  (staged, user-level) becomes relevant for that project's sessions.
