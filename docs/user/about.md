# Was ist die Werkbank?

Die Werkbank ist ein Ticket-System nach dem Vorbild von Jira, gebaut für die Arbeit mit
Claude-Code-Agenten.

Die Idee: Du (oder ein Agent in deinem Auftrag) schreibst Tickets — Aufgaben,
Fehlerberichte, Ideen. Jedes Ticket kann einem Agenten zugewiesen werden. Die
zugewiesenen Agenten arbeiten ihre Tickets dann selbstständig ab und melden das
Ergebnis zurück.

So behältst du den Überblick, was ansteht, wer woran arbeitet und was erledigt ist —
ohne selbst ein Terminal öffnen zu müssen.
